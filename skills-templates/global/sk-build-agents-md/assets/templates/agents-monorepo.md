## Commands

- **Build:** `pnpm build` (compiles TypeScript across all packages)
- **Test (all):** `pnpm test` (runs Vitest across all packages)
- **Test (single):** `pnpm --filter <package> test`
- **Lint:** `pnpm lint --fix`
- **Type-check:** `npx tsc --noEmit`
- **Format:** `pnpm format`

## Architecture

- `packages/contracts/` — Shared Zod schemas, types, validators
- `packages/ui/` — @analygo/ui design system components
- `packages/hatchet/` — Workflow engine, task definitions
- `apps/platform/` — Main consumer application (Next.js)
- `apps/api/` — Backend API service

## Boundaries

- ✅ **Always:** Write to source dirs, run tests, follow naming conventions
- ⚠️ **Ask first:** Adding dependencies, schema changes, CI/CD changes, database migrations
- 🚫 **Never:** Commit secrets or API keys, edit `node_modules/`, bypass depcruise rules

## Workflow

- Branch from `main`, merge via squash
- Commit messages: `type(scope): description` (e.g. `feat(auth): add login flow`)
- PRs require 1 approval and passing CI
